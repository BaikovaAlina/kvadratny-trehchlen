Начерти график по точкам

Дана функция y = x² − 4x + 3. Сначала заполни таблицу значений, затем кликай по координатной плоскости и ставь точки. Когда поставишь все 7 точек — нажми «Проверить».

Задание 1 · 7 точек
Теория: Чтобы построить параболу, составь таблицу: выбери x, подставь в формулу, вычисли y. Точки (x; y) отметь на плоскости и соедини плавной кривой. Вершина параболы — самая низкая (при a > 0) точка.

Определи знаки a и c по графику

Посмотри на параболу: ветви вверх → a > 0, ветви вниз → a < 0. Точка пересечения с осью Oy — это c: выше начала координат → c > 0, ниже → c < 0, в начале → c = 0.

Задание 2 · 4 графика
Как читать график:  •  a — направление ветвей  •  c — где парабола пересекает ось Oy (x=0)  •  Дополнительно: знак b зависит от вершины — если вершина правее оси Oy, то b и a имеют разные знаки.

3

Посчитай a, b, c и дискриминант

По функции выпиши коэффициенты и вычисли D = b² − 4ac. Знак D сразу говорит, сколько будет корней.

Задание 3 · 4 функции
Порядок: 1) Найди a — число перед x²   2) b — перед x   3) c — свободный член   4) D = b² − 4·a·c. Не забудь про знаки! Например, в y = −x² + 5x − 6: a=−1, b=5, c=−6.

4

Найди корни по формуле

Реши уравнение ax² + bx + c = 0 по формуле x = (−b ± √D) / 2a. Введи корни (если их два — через пробел или запятую).

Задание 4 · 4 уравнения
Алгоритм: 1) Вычисли D   2) Если D < 0 — корней нет   3) Если D = 0 — один корень x = −b/2a   4) Если D > 0 — два корня с ±. Всегда проверяй подстановкой!
