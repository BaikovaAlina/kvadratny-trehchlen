# Квадратный трёхчлен — интерактивный тренажёр

Интерактивная учебная презентация-сайт по теме «Квадратный трёхчлен» для 8–9 класса.

## Блоки заданий
1. **Начерти график по точкам** — таблица значений для y = x² − 4x + 3 + кликабельная координатная плоскость (7 точек) + конструктор своей параболы.
2. **Определи знаки a и c по графику** — 4 параболы, выбор знака a (ветви) и c (пересечение с Oy).
3. **Посчитай a, b, c и дискриминант** — 4 функции, ввод a, b, c, D = b² − 4ac с проверкой.
4. **Найди корни по формуле** — 4 уравнения, формула x = (−b ± √D) / 2a, пошаговые решения.

## Запуск
Просто открой `index.html` в браузере — всё в одном файле, без зависимостей и интернета.
